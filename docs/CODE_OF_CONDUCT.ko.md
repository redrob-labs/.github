# 행동 규범

English: [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)

## 짧은 판

직설적으로, 그리고 친절하게. 사람이 아니라 코드를 비판합니다. 반대되는 증거가 나오기 전까지는
상대가 유능하고 선의로 행동한다고 가정합니다.

## 기대되는 행동

- 하려는 말을 분명히 합니다. 의견 차이는 환영이고, 경멸은 아닙니다.
- 눈앞의 변경을 리뷰합니다. "Y 때문에 X가 깨진다"는 쓸모가 있고, "아마추어 같다"는 없습니다.
- 메인테이너가 범위나 방향을 이유로 변경을 받지 않을 수 있고, 그것이 당신에 대한 평가는
  아니라는 점을 받아들입니다.
- 이슈와 논의에서 영어와 한국어 모두 괜찮습니다. 상대의 영어를 고쳐 주는 것으로 답을
  대신하지 마십시오.
- 보안 정책을 지킵니다. 취약점은 비공개로 신고하고, 공개 이슈에는 절대 쓰지 않습니다.

## 용인되지 않는 행동

- 괴롭힘, 모욕, 비하하는 언사. 정체성, 배경, 경력 수준에 대한 것을 포함합니다.
- 성적인 언어나 이미지, 원치 않는 개인적 접근.
- 동의 없이 남의 사적 정보를 공개하는 일.
- 지속적인 방해. 이미 결론이 난 결정을 다시 끌어내 재론하기, 스레드에 떼로 몰려들기,
  리뷰어의 시간을 의도적으로 낭비하기.

## 적용 범위

이 문서는 모든 프로젝트 공간에 적용됩니다. 이슈, 풀 리퀘스트, 디스커션, 커밋 메시지,
코드 주석이 모두 포함되며, 프로젝트를 대표하는 자리에서는 공개된 공간에서도 적용됩니다.

## 집행

우려되는 일은 `conduct@redrob.ai` 로 알려 주십시오. 신고는 메인테이너가 비밀로 처리하며,
피할 수 있는 한 신고 대상이 된 사람은 처리에 참여하지 않습니다.

메인테이너는 경고, 콘텐츠 편집이나 삭제, 계정 차단을 할 수 있습니다. 조치는 비례합니다.
첫 실수는 보통 차단이 아니라 사적인 한마디입니다. 신고가 인정된 경우 신고자에게 무엇을 했는지
알립니다.

메인테이너는 이 문서에서 면제되는 것이 아니라 이 문서의 적용을 받습니다.
