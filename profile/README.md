## Redrob Labs

Applied AI research at Redrob. Open weights, open evals, Apache-2.0. Inference under hardware
constraints, evaluation for high-fertility languages.

Korean is a first-class locale in everything here, not a translation layer bolted on afterwards.

### Applications

| | |
|---|---|
| [redrob-code](https://github.com/redrob-labs/redrob-code) | AI coding agent for the terminal |
| [redrob-cowork](https://github.com/redrob-labs/redrob-cowork) | Desktop and MCP app for working with agents on your own files |
| [redrob-office](https://github.com/redrob-labs/redrob-office) | Docs, Sheets, Slides, PDF, Markdown and Hangul editors in one window |
| [redrob-design](https://github.com/redrob-labs/redrob-design) | Prompt-driven design editor for `.fig` and `.pen` files |
| [redrob-canvas](https://github.com/redrob-labs/redrob-canvas) | Agentic raster graphics editor in Rust and Qt Quick |
| [redrob-query](https://github.com/redrob-labs/redrob-query) | JVM-free database client for PostgreSQL, MySQL, SQLite and MongoDB |
| [redrob-recall](https://github.com/redrob-labs/redrob-recall) | Local-first file search with grounded answers |
| [redrob-studio](https://github.com/redrob-labs/redrob-studio) | Image and audio tools backed by ComfyUI on your own GPU |

### Research and evaluation

| | |
|---|---|
| [redrob-eval](https://github.com/redrob-labs/redrob-eval) | LLM eval workbench: verifiable prompts, blind preference, GEPA, self-hosted vLLM |
| [redrob-verify](https://github.com/redrob-labs/redrob-verify) | Open harness for document OCR, forgery detection and face matching |
| [redrob-image](https://github.com/redrob-labs/redrob-image) | Open-weight text-to-image model, free for commercial use |

### Contributing

Outside contributions are welcome, and most of these repositories are forks, which changes the
rules more than anything else:

- [CONTRIBUTING.md](https://github.com/redrob-labs/.github/blob/main/CONTRIBUTING.md) ([한국어](https://github.com/redrob-labs/.github/blob/main/CONTRIBUTING.ko.md)): what gets merged quickly, and what needs a discussion first
- [FORKS.md](https://github.com/redrob-labs/.github/blob/main/FORKS.md) ([한국어](https://github.com/redrob-labs/.github/blob/main/FORKS.ko.md)): read before your first change
- [SECURITY.md](https://github.com/redrob-labs/.github/blob/main/SECURITY.md): privately, never as a public issue
- [CODE_OF_CONDUCT.md](https://github.com/redrob-labs/.github/blob/main/CODE_OF_CONDUCT.md) ([한국어](https://github.com/redrob-labs/.github/blob/main/docs/CODE_OF_CONDUCT.ko.md))
